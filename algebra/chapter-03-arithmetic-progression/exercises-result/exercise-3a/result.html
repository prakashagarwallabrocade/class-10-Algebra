ପଦ୍ଧତି : ପ୍ରଥମେ ଦୁଇଟି କ୍ରମିକ ପଦର ବିୟୋଗଫଳରୁ ସାଧାରଣ ଅନ୍ତର d ନିର୍ଣ୍ଣୟ କରାଯାଏ । ନିର୍ଦ୍ଦିଷ୍ଟ ପଦ ପାଇଁ $t_n = a + (n - 1)d$ ସୂତ୍ର ବ୍ୟବହାର କରି ବିକଳ୍ପ ମଧ୍ୟରୁ ଠିକ୍ ଉତ୍ତର ବଛାଯାଏ ।

(i) 1, 2, 3, 4, .... ଅନୁକ୍ରମରେ $t_8$ = .................... [(a) 6 (b) 7 (c) 8 (d) 9 ]

  1. ଦତ୍ତ ପଦଗୁଡ଼ିକରେ 1 ଯୋଗ କଲେ,
    \frac{a}{b + c} + 1 = \frac{a + b + c}{b + c}, \ldots \Rightarrow \frac{a + b + c}{b + c}, \frac{a + b + c}{c + a}, \frac{a + b + c}{a + b} \text{ A.P.}
  2. $(a + b + c) \neq 0$ ଦ୍ୱାରା ହରଣ କଲେ,
    \frac{1}{b + c}, \frac{1}{c + a}, \frac{1}{a + b} \text{ A.P.}

ଉତ୍ତର : $\frac{1}{b + c}, \frac{1}{c + a}, \frac{1}{a + b}$ A.P. ରେ ଅଛନ୍ତି । (ପ୍ରମାଣିତ)

24ପ୍ରଶ୍ନ

ଯଦି କୌଣସି A.P.ର ପ୍ରଥମ ପଦ a ଏବଂ ଶେଷ ପଦ $l$ ହୁଏ, ପ୍ରମାଣ କର ଯେ ଅନୁକ୍ରମର ପ୍ରଥମରୁ r- ତମ ପଦ ଏବଂ ଶେଷରୁ r-ତମ ପଦର ସମଷ୍ଟି, ପ୍ରଥମ ଓ ଶେଷ ପଦର ସମଷ୍ଟି ସହିତ ସମାନ ।

ପଦ୍ଧତି : ପ୍ରଥମରୁ r ତମ ପଦ $a + (r - 1)d$ ଏବଂ ଶେଷରୁ r ତମ ପଦ, ଶେଷ ପଦ $\ell$ ରୁ $(r - 1)$ ଥର d ବିୟୋଗ କଲେ ମିଳେ ।

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • n ତମ ପଦର ସୂତ୍ର
    t_n = a + (n - 1)d
    📖 ଅନୁଚ୍ଛେଦ 3.2.1
  1. ପ୍ରଥମରୁ r ତମ ପଦ :
    a + (r - 1)d
  2. ଶେଷରୁ ଓଲଟା ଦିଗରେ ଅନୁକ୍ରମ $\ell, \ell - d, \ell - 2d, \ldots$ ; ଏହାର r ତମ ପଦ :
    \ell - (r - 1)d
  3. ଯୋଗ କଲେ,
    a + (r - 1)d + \ell - (r - 1)d = a + \ell

ଉତ୍ତର : ସମଷ୍ଟି $= a + \ell$ = ପ୍ରଥମ ଓ ଶେଷ ପଦର ସମଷ୍ଟି । (ପ୍ରମାଣିତ)

25ପ୍ରଶ୍ନ

ଗୋଟିଏ ସମାନ୍ତର ପ୍ରଗତିର ପ୍ରଥମ p ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି r, ପ୍ରଥମ q ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି s ଏବଂ ସାଧାରଣ ଅନ୍ତର d, ହେଲେ ପ୍ରମାଣ କର ଯେ, $\frac{r}{p} - \frac{s}{q} = (p - q)\frac{d}{2}$ ହେବ ।

ପଦ୍ଧତି : ପ୍ରଥମ ପଦ A ନେଇ $S_p = r$ ଓ $S_q = s$ ଲେଖି ଉଭୟକୁ ପଦସଂଖ୍ୟା ଦ୍ୱାରା ହରଣ କରାଯାଏ; ବିୟୋଗ କଲେ A ଲୋପ ପାଏ ।

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • n ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି
    S_n = \frac{n}{2}\{2a + (n - 1)d\}
    📖 ଅନୁଚ୍ଛେଦ 3.2.2
  1. $r = \frac{p}{2}\{2A + (p - 1)d\}$ ଓ $s = \frac{q}{2}\{2A + (q - 1)d\}$ ରୁ,
    \frac{r}{p} = A + \frac{(p - 1)d}{2},\qquad \frac{s}{q} = A + \frac{(q - 1)d}{2}
  2. ବିୟୋଗ କଲେ,
    \frac{r}{p} - \frac{s}{q} = \frac{(p - 1) - (q - 1)}{2}d = (p - q)\frac{d}{2}

ଉତ୍ତର : $\frac{r}{p} - \frac{s}{q} = (p - q)\frac{d}{2}$ (ପ୍ରମାଣିତ)

26ପ୍ରଶ୍ନ

ଗୋଟିଏ ସମାନ୍ତର ଶ୍ରେଣୀର ପ୍ରଥମ p, q, r ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି a, b, c ହେଲେ ପ୍ରମାଣ କର ଯେ, $\frac{a}{p}(q - r) + \frac{b}{q}(r - p) + \frac{c}{r}(p - q) = 0$ ହେବ ।

ପଦ୍ଧତି : ପ୍ରଥମ ପଦ A ଓ ସାଧାରଣ ଅନ୍ତର D ନେଇ $\frac{a}{p}, \frac{b}{q}, \frac{c}{r}$ କୁ A ଓ D ମାଧ୍ୟମରେ ଲେଖି ପ୍ରଶ୍ନ 21 ପରି A ଓ D ର ସହଗ ଶୂନ ଦେଖାଯାଏ ।

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • n ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି
    S_n = \frac{n}{2}\{2a + (n - 1)d\}
    📖 ଅନୁଚ୍ଛେଦ 3.2.2
  1. ପ୍ରଶ୍ନ 25 ପରି,
    \frac{a}{p} = A + \frac{(p - 1)D}{2},\quad \frac{b}{q} = A + \frac{(q - 1)D}{2},\quad \frac{c}{r} = A + \frac{(r - 1)D}{2}
  2. ବାମପାର୍ଶ୍ୱରେ ବସାଇଲେ A ର ସହଗ $(q - r) + (r - p) + (p - q) = 0$ ଏବଂ $\frac{D}{2}$ ର ସହଗ :
    (p - 1)(q - r) + (q - 1)(r - p) + (r - 1)(p - q) = 0
  3. ତେଣୁ,
    \frac{a}{p}(q - r) + \frac{b}{q}(r - p) + \frac{c}{r}(p - q) = 0

ଉତ୍ତର : $\frac{a}{p}(q - r) + \frac{b}{q}(r - p) + \frac{c}{r}(p - q) = 0$ (ପ୍ରମାଣିତ)

27ପ୍ରଶ୍ନ

କୌଣସି A.P. ର $t_p = q$, $t_q = p$ ହେଲେ, ପ୍ରମାଣ କର ଯେ $t_m = p + q - m$ ।
ସୂଚନା : $a + (p - 1)d = q$ ଓ $a + (q - 1)d = p$ କୁ ସମାଧାନ କରି a ଓ d ନିରୂପଣ କରି $t_{pq}$ ନିର୍ଣ୍ଣୟ କର ।

ପଦ୍ଧତି : ସୂଚନା ଅନୁସାରେ ଦୁଇଟି ସରଳ ସମୀକରଣ ସମାଧାନ କରି a ଓ d ନିର୍ଣ୍ଣୟ କରାଯାଏ ଏବଂ $t_m$ ସୂତ୍ରରେ ବସାଯାଏ ($p \neq q$) ।

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • n ତମ ପଦର ସୂତ୍ର
    t_n = a + (n - 1)d
    📖 ଅନୁଚ୍ଛେଦ 3.2.1
ଟିପ୍ପଣୀ : ସୂଚନାରେ $t_{pq}$ ନିର୍ଣ୍ଣୟ କରିବାକୁ କୁହାଯାଇଛି, ଯାହା ପ୍ରଶ୍ନ ସହ ମେଳ ଖାଏ ନାହିଁ; ସୂତ୍ରରୁ $t_{pq} = p + q - pq$ ।
  1. ଦତ୍ତ :
    a + (p - 1)d = q \quad \ldots(1), \qquad a + (q - 1)d = p \quad \ldots(2)
  2. (1) ରୁ (2) ବିୟୋଗ କଲେ,
    (p - q)d = q - p \Rightarrow d = -1
  3. (1) ରେ ବସାଇଲେ,
    a = q + (p - 1) = p + q - 1
  4. ତେଣୁ,
    t_m = (p + q - 1) + (m - 1)(-1) = p + q - m
  5. ଯାଞ୍ଚ : $m = p$ ରେ $t_p = q$ ଓ $m = q$ ରେ $t_q = p$ ।

ଉତ୍ତର : $t_m = p + q - m$ (ପ୍ରମାଣିତ)

28ପ୍ରଶ୍ନ

କୌଣସି A.P. ର $S_m = n$, $S_n = m$ ହେଲେ, ପ୍ରମାଣ କର ଯେ $S_{m+n} = -(m + n)$ ହେବ ।

ପଦ୍ଧତି : $S_m = n$ ଓ $S_n = m$ କୁ $2a + (k - 1)d$ ରୂପରେ ଲେଖି ବିୟୋଗ କଲେ d ମିଳେ ($m \neq n$); ତାପରେ $2a + (m + n - 1)d$ ର ମାନ ନିର୍ଣ୍ଣୟ କରାଯାଏ ।

ବ୍ୟବହୃତ ସୂତ୍ର (ପୂର୍ବପରି)
  • n ସଂଖ୍ୟକ ପଦର ସମଷ୍ଟି
    S_n = \frac{n}{2}\{2a + (n - 1)d\}
    📖 ଅନୁଚ୍ଛେଦ 3.2.2
  1. ଦତ୍ତ ସର୍ତ୍ତରୁ,
    2a + (m - 1)d = \frac{2n}{m} \quad \ldots(1), \qquad 2a + (n - 1)d = \frac{2m}{n} \quad \ldots(2)
  2. (1) ରୁ (2) ବିୟୋଗ କଲେ,
    (m - n)d = \frac{2(n^2 - m^2)}{mn} \Rightarrow d = -\frac{2(m + n)}{mn}
  3. (1) ରେ nd ଯୋଗ କଲେ,
    2a + (m + n - 1)d = \frac{2n}{m} + n\left(-\frac{2(m + n)}{mn}\right) = \frac{2n - 2m - 2n}{m} = -2
  4. ତେଣୁ,
    S_{m+n} = \frac{m + n}{2}\{2a + (m + n - 1)d\} = \frac{m + n}{2}(-2) = -(m + n)

ଉତ୍ତର : $S_{m+n} = -(m + n)$ (ପ୍ରମାଣିତ)
