3ପ୍ରଶ୍ନ

ପଦ୍ଧତି : n ତମ ପଦକୁ n ର ପଲିନୋମିଆଲ୍ ରୂପେ ଲେଖି $\Sigma n, \Sigma n^2, \Sigma n^3$ ସୂତ୍ର ପ୍ରୟୋଗ କରାଯାଏ (ଉଦାହରଣ 11, 12 ପରି) । ନିର୍ଦ୍ଦିଷ୍ଟ n ପାଇଁ $S_n$ ରେ ସେହି ମାନ ବସାଯାଏ ।

(a) $7 \times 15 + 8 \times 20 + 9 \times 25 + \ldots$ ର $t_n$ ନିର୍ଣ୍ଣୟ କର ।

ବ୍ୟବହୃତ ସୂତ୍ର

  • A.P. ର n ତମ ପଦ
    t_n = a + (n - 1)d
    📖 ଅନୁଚ୍ଛେଦ 3.2.1
  1. ପ୍ରଥମ ଗୁଣକ 7, 8, 9, … ($a = 7, d = 1$) ର n ତମ ପଦ $n + 6$; ଦ୍ୱିତୀୟ ଗୁଣକ 15, 20, 25, … ($a = 15, d = 5$) ର n ତମ ପଦ $5n + 10$ :
    t_n = (n + 6)(5n + 10) = 5n^2 + 40n + 60
  2. ଯାଞ୍ଚ : $n = 2$ ରେ $20 + 80 + 60 = 160 = 8 \times 20$ ।

ଉତ୍ତର : $t_n = 5n^2 + 40n + 60$

(b) $6\Sigma n^2 + 4\Sigma n^3$ ର ସରଳୀକୃତ ମାନ ନିର୍ଣ୍ଣୟ କର ।

ବ୍ୟବହୃତ ସୂତ୍ର

  • ଗଣନ ସଂଖ୍ୟା, ବର୍ଗ ଓ ଘନର ଯୋଗଫଳ
    \Sigma n = \frac{n(n + 1)}{2},\quad \Sigma n^2 = \frac{n(n + 1)(2n + 1)}{6},\quad \Sigma n^3 = \left\{\frac{n(n + 1)}{2}\right\}^2,\quad \Sigma 1 = n
    📖 ଅନୁଚ୍ଛେଦ 3.3 — ସୂତ୍ର (1), (4), (5), Σ ଚିହ୍ନ
  1. ସୂତ୍ର ବସାଇଲେ,
    6 \cdot \frac{n(n + 1)(2n + 1)}{6} + 4 \cdot \frac{n^2(n + 1)^2}{4} = n(n + 1)(2n + 1) + n^2(n + 1)^2
  2. $n(n + 1)$ ସାଧାରଣ ଉତ୍ପାଦକ ନେଲେ,
    n(n + 1)\{2n + 1 + n(n + 1)\} = n(n + 1)(n^2 + 3n + 1)

ଉତ୍ତର : $n(n + 1)(n^2 + 3n + 1)$

(c) $1 \times 2 + 2 \times 3 + 3 \times 4 \ldots + n(n + 1)$ ପାଇଁ $S_n$ ଓ $S_{20}$ ନିର୍ଣ୍ଣୟ କର ।

    📖 ଅନୁଚ୍ଛେଦ 3.3 — ସୂତ୍ର (1), (4), (5), Σ ଚିହ୍ନ

  2. $n = 20$ :
