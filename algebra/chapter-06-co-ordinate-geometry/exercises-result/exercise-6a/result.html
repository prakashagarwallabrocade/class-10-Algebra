  2. C(x, y) ପାଇଁ $CA^2 = CB^2$ :
    x^2 + (y - 3)^2 = (x - 4)^2 + (y - 3)^2 \Rightarrow x^2 = x^2 - 8x + 16 \Rightarrow x = 2
  3. $CA^2 = AB^2 = 16$ :
    2^2 + (y - 3)^2 = 16 \Rightarrow (y - 3)^2 = 12 \Rightarrow y - 3 = \pm 2\sqrt{3}
  4. \therefore C = (2, 3 + 2\sqrt{3}) \text{ ବା } (2, 3 - 2\sqrt{3})
  5. ଯାଞ୍ଚ : ଉଭୟ ପାଇଁ
    CA = CB = \sqrt{2^2 + (2\sqrt{3})^2} = \sqrt{4 + 12} = 4 = AB

ଉତ୍ତର : $(2, 3 + 2\sqrt{3})$ ବା $(2, 3 - 2\sqrt{3})$
